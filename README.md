# wolves.glorbnorb.com — team schedule site

Schedule, RSVPs, and practice-time polls for our softball and soccer teams.
Static site (GitHub Pages) + Supabase free tier for live data.

The 2026 batting-stats viewer that used to live here was retired 2026-08-18;
it remains in git history before that date.

Dev: `node schedule_lib.test.js` runs the pure-logic tests.
